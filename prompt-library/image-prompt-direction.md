# 生图提示词方向

完整 Skill：[cinematic-image-prompt-skill](https://github.com/wusuyee-beep/cinematic-image-prompt-skill)

## 目标

把用户的画面想法改写成主体明确、空间稳定、光线可执行、色彩干净的静态图像提示词。重点不是堆砌“8K、杰作、超高清”等质量词，而是建立可验证的画面关系。

## 核心结构

1. **主体**：身份、数量、外观、材质和不可变属性。
2. **动作与关系**：姿态、表情、接触点、视线与主体之间的关系。
3. **空间布局**：左右前后、高低、遮挡、尺度、留白和视觉中心。
4. **机位与光学表现**：摄影机位置、拍摄距离、景别、视场、焦点和感知景深。
5. **视觉结构**：构图、光源、色彩、影调、材质与成像质感。
6. **输出约束**：画幅、必要文字、参考图职责和针对性负向约束。

## 与视频提示词的关键区别

- 生图不写时长、时间码和摄影机运动路线。
- 生图不套用“无 BGM，无配乐！”等音频规则。
- 单帧重点是一个明确瞬间，不展开完整动作因果链。
- 焦段不能独立决定透视；摄影机位置和拍摄距离先于焦段数值。
- 多主体必须逐一绑定属性、动作与位置，防止漏主体和串色。

## 默认输出

```text
【正向提示词】
媒介与主风格；主体、数量与属性；动作和关系；场景与空间布局；构图与视觉中心；机位、景别、视场与焦点；光源；色彩与影调；材质与成像质感；画幅。

【负向约束】
只列当前画面最可能出现的错误。
```
