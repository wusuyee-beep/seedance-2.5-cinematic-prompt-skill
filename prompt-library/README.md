# 生成资料库

这个目录用于索引不同生成媒介的提示词方法。每个方向保持独立 Skill：共享视觉语言基础，但不混用媒介特有规则。

| 方向 | Skill | 重点 | 不应混入 |
|---|---|---|---|
| 生视频 | `$didi-ok-video-prompt` | 时间、动作因果、运镜、连续性、物理反馈、同期声 | 静态图像的单帧模板 |
| 生图 | [`$cinematic-image-prompt`](https://github.com/wusuyee-beep/cinematic-image-prompt-skill) | 主体与属性绑定、空间布局、视觉中心、光线、色彩、材质 | 时长、时间码、运镜路径、BGM 与同期声规则 |

## 共同基础

- 明确主体、数量、身份和关键属性。
- 建立前后左右、遮挡、尺度与视觉层级。
- 让机位、视场、焦点与空间关系保持一致。
- 光源必须有来源、方向和画面作用。
- 使用针对当前生成风险的约束，不堆砌通用质量词。

## 选用方式

- 最终结果是一张静态图片：使用生图 Skill。
- 最终结果包含时序、人物动作、摄影机运动或声音：使用视频 Skill。
- 先生成关键帧再生成视频：先用生图 Skill 固定人物、构图和美术，再用视频 Skill描述动作、运镜、连续性与声音；不要把两个 Skill 的完整模板直接拼接。
