# DDOk 提示词方法

## 核心公式

电影级视频提示词 = 全局视觉合同 + 空间拓扑 + 时间因果链 + 摄影机路径 + 表演潜台词 + 焦点行为 + 物理反馈 + 同期声 + 失败防护。

DDOk 案例真正可迁移的不是“长”，而是把抽象审美转化成可被模型执行和验证的画面证据。

## 九层镜头建模

| 层级 | 要回答的问题 | 有效写法 |
| --- | --- | --- |
| 视觉合同 | 成片像什么？ | 写实电影、纪录片现场感、画幅、色彩、光线、是否一镜到底 |
| 空间拓扑 | 人、物、镜头在哪里？ | 前景/中景/背景、左右关系、玻璃内外、人物间距离 |
| 起止帧 | 第一眼和最后一眼是什么？ | 首帧主体与构图；尾帧揭示或情绪落点 |
| 时间链 | 事情按什么顺序发生？ | 观察→靠近→接触→反应→结果，使用明确连接词 |
| 摄影机 | 操作者怎样跟上事件？ | 跟拍、绕后、越肩、后拉、长焦推进、遮挡后重构图 |
| 焦点 | 观众此刻看谁？ | 焦点落错对象后拉回；前景经过时自然虚化；焦点接力对白 |
| 表演 | 潜台词怎样可见？ | 搓手、轻咳、眼神回避、克制微笑、反应延迟 |
| 物理 | 物体为何这样运动？ | 摩擦、惯性、重量、碰撞、支撑消失、二次弹跳 |
| 声音 | 空间如何被听见？ | 空调低频、鞋底、衣料、呼吸、电流、远近不同的碰撞声 |

## 七个关键原则

### 1. 先空间，后事件

复杂动作前先固定房间形状、光源、人物站位和视线通道。空间关系不清时，模型会用跳切或角色瞬移补洞。

### 2. 用镜头路线代替形容词

“高级、电影感、紧张”不够。改写为摄影机可执行的动作：从人物耳侧擦过、在人群肩膀缝隙寻找画作、跟拍时因遮挡短暂失焦、突发声响后快速回摇。

### 3. 真实来自不完美

真实手持不是随机剧烈抖动，而是呼吸式上下浮动、步伐造成的轻微横移、自动对焦迟疑、操作者对突发事件晚半拍。缺陷应有原因和限度。

### 4. 让物理过程有中间态

不要从 A 直接跳到 B。滚动要有接触面变化、卡顿和重心偏移；抓取要有手指靠近、接触、施力、离地；爆裂要有支撑消失、散射、碰撞、滚动和人物反应。

### 5. 让群像各自生活

群体不能像同一个演员。分配不同的微动作、注意方向与反应时差。背景人物保持低强度活动，不抢主事件。

### 6. 用遮挡和焦点讲故事

遮挡可以揭示空间、隐藏转场或控制信息。焦点可作为叙事接力棒：谁说话，镜头靠近谁；关键句出现时，焦点从脸移向物或从前景拉向远处。

### 7. 把负面词写成故障防护

只禁止已经能预见的错误：数字溶解、镜头越过人群、人物齐看镜头、物体塑料感、字幕乱入。不要用泛化负面词替代正向描述。

## 五种常用结构

### 微观物理

尺度锚点 → 材质细节 → 受力关系 → 连续运动 → 微距焦点 → 放大的材质声音。

### 观察式群戏

世界观连续性 → 摄影机跟随者 → 空间揭示 → 多角色反应 → 关键事件 → 延迟反应 → 讽刺性收束。

### 发布会/演讲

公共标识或环境特写 → 后拉揭示发言者 → 克制表演与完整台词 → 关键词触发焦点偏移 → 现场环境声与信息禁区。

### 前景交互

前景物体清晰 → 人物从远处进入 → 手向镜头靠近形成透视 → 接触与拾取 → 人物检查 → 极短对白与同期声。

### 群像对白

建立全景 → 镜头移到说话者背后 → 对白接力 → 每次焦点在人物和共同观看物之间转移 → 最后一句触发视觉证据 → 后拉形成群体余韵。

## 常见失败与修正

| 失败 | 原因 | 修正 |
| --- | --- | --- |
| 长提示词仍像广告 | 只有美术形容词 | 加入操作失误、环境底噪、克制表演和观察视角 |
| 一镜到底变成隐形切镜 | 空间路径不连续 | 写清摄影机每一步位置、遮挡物和转向依据 |
| 角色瞬间换装或换脸 | 连续属性未锁定 | 在开头建立角色与服装锚点，后文用指代而非重新描述 |
| 物体像塑料或无重量 | 只有颜色形状 | 写尺度、表面、接触面、摩擦、惯性、碰撞声音 |
| 全员同步惊讶 | 缺少反应时差 | 指定有人后退、有人僵住、有人晚一步回头 |
| 对白像配音 | 未写说话状态 | 指定气息、音量、口音、身体动作和镜头位置 |
| 镜头炫技但不叙事 | 运镜没有动机 | 每次移动都绑定人物、声音、视线或信息揭示 |

## 案例使用规则

读取 `cases.md` 时，先找与当前任务最接近的“镜头机制”，再抽取结构。不得默认复用 Candy 世界观、陌生面孔、无 BGM、16:9 或一镜到底；这些是案例设定，不是普遍规则。
