# 六个 DiDi_OK Case 逐项编码

本文件把 `cases.md` 的六个原始提示词块逐项编码。百分比只表示该模块在六案中的显性出现频率，不代表审美价值。规则分三级：

- `6/6（100%）`：六案共同骨架，作为固定生成规则。
- `4–5/6（67%–83%）`：高频模块，默认优先；不适用时可以省略。
- `1–3/6（17%–50%）`：镜头类型模块，只在对应任务中调用。

## 共同骨架：6/6（100%）

| 模块 | 六案中的共同表现 | 生成规则 |
| --- | --- | --- |
| 写实视觉合同 | 微观纪录片、实拍电影、记者现场或现代美术馆，但都锚定真实摄影 | 开头必须先固定写实程度、摄影媒介感、画幅与整体气质 |
| 明确画幅 | 六案都写明画幅；Case 1 为竖幅，其余为 16:9 | 画幅是必写模块，但具体比例根据任务决定，不机械统一为 16:9 |
| 具体主体 | 蚂蚁与糖果、政客与跟班、发言人、工作人员、女孩、群像均有可见外观和状态 | 根据主题充分补全年龄、外貌、服装、身份、材质和情绪基线 |
| 空间与构图 | 每案都交代机位以及前景、中景、背景或内外关系 | 必须让人能画出人物、道具和摄影机的相对位置 |
| 摄影机行为 | 微距呼吸、记者跟拍、后拉、绕后、长焦推进、贴地仰拍等 | 运镜必须写方向、速度、景别变化、动机和操作者反应 |
| 焦点/视觉注意力 | 六案都通过浅景深、焦点锁定、失焦、拉焦或前景清晰度管理注意力 | 必须写观众此刻看什么，以及焦点怎样变化 |
| 连续动作因果 | 所有动作都有先后顺序和可见结果 | 按起始状态→触发→中间态→反应→结果组织 |
| 真实现场声音 | 六案都具体列出环境、材质、动作或人声 | 声音必须对应空间、距离、材质与动作 |
| 无 BGM/无配乐 | 六案全部明确排除背景音乐 | 每条必须单独写“无 BGM，无配乐！”；只写同期声、环境声、动作声与对白 |
| 故障防护 | 六案分别排除塑料感、血腥、字幕、慢动作、数字转场、越位等 | 结尾必须写与当前镜头高度相关的禁止项 |
| 强约束语言 | 六案都出现“必须、始终、严格、全程、绝不”等绝对词 | 高风险约束必须沿用这种语言强度；按用户要求以感叹号突出关键项 |

## 高频模块：4–5/6（67%–83%）

| 模块 | 频率 | 出现 Case | 调用规则 |
| --- | ---: | --- | --- |
| 人物微表演与潜台词 | 5/6，83% | 2、3、4、5、6 | 有人物时默认写呼吸、眼神、停顿、局促动作与反应时差；纯微观物理场景可不写 |
| 明确尾部收束 | 5/6，83% | 2、3、4、5、6 | 叙事或人物镜头默认给结尾视觉落点；持续观察型自然过程可以开放收束 |
| 一镜到底 | 4/6，67% | 3、4、5、6 | 只在连续空间体验适合时采用；复杂实验群戏可以多机位切换 |
| 具体物理反馈 | 4/6，67% | 1、2、4、5 | 有抓取、滚动、碰撞、爆裂、遮挡或搬运时必须写尺度、接触、受力、阻力、惯性与落点 |
| 完整人物对白 | 4/6，67% | 2、3、5、6 | 有对白时必须逐字给出台词，并写语气、音量、口音、身体动作、镜头与他人反应 |
| 群体差异化活动 | 4/6，67% | 1、2、4、6 | 多主体场景必须分配不同动作与反应时差，避免整齐同步 |

| 前景近大远小交互 | 1/6，17% | 手向镜头靠近、拾取或检查前景物体时 |
| 群像对白焦点接力 | 1/6，17% | 多人围绕共同观看物交谈时 |

| 长焦寻找视觉证据 | 2/6，33% | 关键词或台词需要触发对关键细节的揭示时 |

## 不应从六案误推为固定规则

- `16:9` 不是唯一画幅；画幅必写，但比例随任务选择。
- `一镜到底` 不是所有任务都适用；Case 2 明确使用多机位切换。
- `陌生面孔`、糖果、实验室、美术馆、白色科研服、低饱和与冷白光都不是通用设定。
- 自动对焦失误、剧烈手持或长焦推进是有动机的摄影事件，不应每条机械堆叠。
- 台词不是必需模块，但只要有对白，就必须完整、具体且与表演和镜头同步。
- 原案例没有统一时长结构；不得主动把秒数、时间码或建议时长写进 Prompt 正文。完整 Prompt 审核通过后，必须依据动作、对白、运镜、反应与收束容量，在正文之外独立给出推荐时长。
