# 输出模板

## 默认长提示词模板

```markdown
[视觉合同：画幅、媒介感、写实程度、色彩、镜头形式；仅在用户已指定时写时长]

[首帧与空间：机位、前中后景、主体、光线、材质、连续性锚点]

[时间链：摄影机如何移动；人物与物体依次做什么；动作之间的因果和物理反馈]

[关键表演或对白：潜台词、微动作、焦点变化、其他人物的反应时差]

[收束画面：最终构图、视觉揭示或情绪落点]

[声音：同期声、对白]

[BGM：必须单独写明“无 BGM，无配乐！”]

[必要禁止项]
```

Prompt 代码块结束后另列：

```text
【推荐时长】
首选：[X 秒]
依据：[决定容量的核心动作、对白、运镜、反应或尾帧停留]
```

只有存在明确节奏取舍时才增加一个备选。不要把推荐时长复制进 Prompt 正文。

## 图生视频模板

```markdown
首帧严格延续参考图中的[人物身份/服装/道具/构图/光线/空间关系]，不改变[关键不变量]。

镜头从[首帧景别与机位]开始。[主体]先[微动作]，随后[触发动作]；摄影机因[叙事动机]沿[路线]移动，并在[对象 A]与[对象 B]之间[对焦行为]。[关键物体]受到[力]后，以[符合尺度与材质的运动]产生[结果]。[人物或群体]按[先后顺序]反应。

尾帧停在[明确构图]。保留[同期声]；避免[最可能的三到六种故障]。
```

## 用户指定时长后的单镜头模板

```markdown
[起始段：建立画面和动作起点]
[发展段：摄影机跟随核心动作，出现第一次信息变化]
[关键段：关键动作或视觉揭示，写清物理与焦点]
[收束段：人物反应和尾帧收束]
```

只有用户明确要求时间轴时，才把这些动作段换算为具体时间码；否则把节奏融入自然语言。绝不主动在 Prompt 正文添加秒数；正文之后仍需给出独立的推荐时长。

## 模板一：超低机位微观物理过程

适用：微小生物、食物、颗粒、零件、液滴、纤维、微型机械或任何需要证明重量、摩擦和接触的镜头。

```markdown
极度真实可信的实拍质感！[画幅]，[微距纪录片/自然观察]影像。摄影机中心几乎贴着[地面/桌面/液面]，机位高度约等于[微观主体]的[相对高度]，从[方向]观察，绝不使用俯视上帝视角。[承载面]具有[湿度、灰尘、颗粒、裂纹、纤维或反光]，这些细节必须成为明确的尺度参照。

[前景主物]距镜头最近，写清其真实尺寸、重量感、透明度/粗糙度、边缘磨损、内部结构、表面附着物和接触阴影；它必须始终保持[材质身份]，绝不能误生成[塑料、碎屑、漂浮物或错误材质]。中景是[主行动组]，左右两侧分别是[副行动组 A/B]，背景只保留[大尺度世界线索]的模糊轮廓，严格处于浅景深之外，不抢夺前景注意力。

[施力者]从[底部/侧面/前方]分别进行[托举/推动/牵引/旋转]，写清足部或工具如何抓住承载面、身体或机构如何发力，以及负载如何反过来压低姿态。主物先克服静摩擦轻微颤动，再缓慢移动；经过[凸起/裂缝/阻碍]时短暂卡住，[施力者]重新调整位置并再次发力，物体发生[滚动/滑移/倾斜]，接触面交替变化，重心先偏移再恢复。不同组的速度和方向必须清楚，绝不融成无方向的随机爬动。

摄影机以[贴地平移/原地观察/短距离跟随]为唯一主要路线。微距手持只保留由呼吸造成的极轻低频漂移；前景主体经过镜头边缘时自然虚化，焦点可短暂落在[指尖/足部/接触点]，随后必须缓慢、明确地回到[主物表面或受力点]。不要随机高频抖动，不要无动机抽焦。

本镜头无对白、无旁白。同期声必须逐一对应材质与动作：[摩擦声]、[卡顿后的细小碰撞]、[滚动/滑移声]、[微小结构振动]和极轻的[环境底噪]；近距离声音被真实放大，但不过度拟音化。

无 BGM，无配乐！

不要广告感，不要微缩玩具感，不要塑料材质，不要漂浮，不要无重量滑行，不要字幕、logo 或屏幕文字。
```

复刻结构：微观视点合同 → 尺度锚点 → 材质身份证 → 多组运动分区 → 施力链 → 阻力与重心中间态 → 微距手持与焦点恢复 → 材质同期声。

## 模板二：制度空间群像与物理突变

适用：实验、审讯、控制室、医疗观察、机构事故、灾难前兆或带黑色幽默的多人物事件。它允许多机位；每次切换都必须补充新信息。

```markdown
写实电影画面，极度真实可信的实拍质感！[画幅]，[观察式纪录片/新闻纪实]运镜。整体气质[冷峻/压抑/荒诞/克制]，所有人物、场景、服装、关键物和光线必须连续一致！无广告感、无滤镜化表演。

摄影机首先跟随[权力人物]与[依附人物]，从[侧后方]贴近移动，再绕到两人背后形成越肩视角。手持晃动来自摄影记者的脚步和紧张呼吸：画面有低频起伏、轻微横向漂移，避让人群时短暂被肩膀遮挡，偶尔因抢拍落错焦点后迅速重新锁定。绝不提前构图等待突发事件。

[权力人物]的外貌、服装、姿态和情绪基线是[具体描述]；[依附人物]通过[小步紧跟、搓手、偷看上级反应、勉强微笑、说话前吞咽]表现[谄媚/恐惧/邀功]，不得只写抽象性格。他一边引导一边以[语言、口音、音量、语气]逐字说：“[完整台词一]。”镜头保持在两人侧后方，[权力人物]以[具体微反应]回应；如有台词，逐字写：“[完整台词二]。”

前方空间按三层建立：外层是[观察人群/控制台]，中间是[玻璃/网格/门框等界面]，内层是[被观察者和行动场]。镜头先以远景证明三层关系，再切中近景展示[行动者]的身体状态，切特写展示[关键人物]的呼吸、眼神和手部。每个机位只承担一种信息，切换前后保持方向、视线和轴线稳定。

[命令者]靠近[话筒/界面/对象]，以[语气]逐字说：“[命令台词]。”[执行者]先[震惊/犹豫/求助]，用[微动作]拖延，再逐字说：“[回应台词]。”镜头转到[控制者]身后，让近处控制者、界面和远处执行者处于同一构图；焦点从近处[控制者]缓慢拉到远处[执行者]。执行者完成[关键动作]，其重量、接触、冲击和声音必须真实。

动作结束后保留一个短暂的无结果停顿。就在[某人物准备转头/开口/站起]的中间态，[突变主体]突然发生[物理突变]。绝不是一帧替换：先写[原支撑消失或形变起点]，再写[材料向外散射/坠落]、[与桌面和地面第一次碰撞]、[二次弹跳/滚动/停下]，以及服装、道具或周围物体失去支撑后的反馈。所有运动必须符合材料尺度、重量和惯性。

群体反应严格错峰：[人物 A]先后退，[人物 B]僵住，[人物 C]晚半拍抬头，[人物 D]压住惊呼；绝不全员同步转头、同步尖叫或同步后退。摄影机因突发声短促后仰，快速回摇时略有过冲，再修正到[核心人物]。

[依附人物]强撑镇定，逐字说：“[解释台词]。”[权力人物]以[克制动作和语气]逐字回答：“[反讽收束台词]。”这句必须重新解释刚才事件，而不是复述结果。

同期声分层存在：[空间设备低鸣]、[衣料与鞋底]、[呼吸]、[话筒或仪器电流声]、[关键冲击]、[突变材料碰撞与滚动]、[远近不同的压抑人声]。对白随人物距镜头远近自然改变音量与空间反射。

无 BGM，无配乐！

不要血腥，不要数字溶解，不要角色瞬移，不要无重量碎片，不要全员同步反应，不要人物看镜头，不要字幕、logo 或屏幕文字。
```

复刻结构：世界合同 → 受限跟随视点 → 权力微表演 → 三层空间 → 命令对白链 → 跨层拉焦 → 行动与空拍 → 中间态突变 → 物理余波 → 错峰反应 → 反讽收束。

## 模板三：公共发言纪录片长镜头

适用：发布会、政策声明、采访、公开演讲、记者会、听证会或任何“表面克制、信息令人不安”的长对白镜头。

```markdown
极度真实可信的实拍质感！严格一镜到底！[画幅]，真实[发布会/记者会/公共活动]现场的手持记者拍摄感。摄影机是挤在人群中的一名记者，视线和移动受到前方人物限制；全程不使用广告式稳定器滑行，不使用柔光和无瑕皮肤。

镜头从[机构标识/场所细节/信息板]的极近特写开始，文字或图形必须清晰、完整、准确，无乱码、无摩尔纹。摄影机保持原机位缓慢 zoom out，从[局部特写]连续展开到[人物与环境同框的景别]；变焦期间保留踮脚站立造成的呼吸式上下浮动、细小横向偏移和一次短暂失焦后重新拉回，绝不随机高频抖动。

随着视野展开，镜头从[发言者]的[耳侧/肩侧]极近距离擦过，短暂看见[皮肤、发丝、衣料]的真实细节，再沿可行路线移到其侧前方。[发言者]的年龄、外貌、服装、站姿、视线对象和公众形象为[具体描述]；他/她始终面向现场观众，不看镜头。背景[标识/空间证据]始终处于可见位置。

[发言者]以[语言与口音]、[语速]、[情绪与潜台词]逐句说：
“[第一句完整台词。]”
“[第二句完整台词。]”
“[第三句完整台词。]”

每一句都写清说话时的微动作、停顿和现场听众的非同步反应，不得用“继续发表讲话”概括。长对白期间摄影机只做少量有动机的修正：[一次构图微调]、[一次前景短暂遮挡]。说到关键词“[关键词]”时，焦点短暂从发言者眼睛游移到背景[标识/证据]，建立语言与机构之间的视觉关联，再勉强拉回发言者脸上；发言者保持[克制表情]，不夸张表演。

同期声包括[快门]、[记者移动]、[衣料摩擦]、[远处低语]、[空调/扩声系统]和发言者真实近场声音。对白必须始终清楚，环境声按距离自然衰减。

无 BGM，无配乐！

不要广告感，不要稳定器漂浮感，不要慢动作，不要字幕，不要画外旁白，不要可见摄像机，不要人物看镜头；除非剧情需要，不要虚构国家信息、国旗或真实品牌。
```

复刻结构：公共压力 → 机构证据特写 → 有动机的变焦 → 人体前景擦过 → 发言者侧前方 → 逐句长对白 → 关键词拉焦 → 公共空间声。

## 模板四：超低机位前景拾取

适用：人物从镜头前拾起、触碰、检查、拆开或移动一个前景物件；强调极端近大远小、手部质感和接触中间态。

```markdown
写实电影画面，[画幅]，极度真实可信的手持纪录片质感！严格一镜到底！摄影机几乎贴着[承载面]，从[散落物/结构缝隙]之间以超低机位[平视/仰拍]；镜头高度低于[主体物高度]，[前景主物]距镜头最近并处于最清晰焦平面。[主物]具有真实的[尺寸、重量、材质、磨损、表面高光、灰尘与接触阴影]，绝不能像塑料模型或漂浮贴图。

[人物]从镜头上方或远处进入。写清年龄、外貌、服装、身份和初始情绪；他/她先[观察主物]，呼吸、目光和身体重心显示[困惑/警惕/好奇]，视线在主物与周围环境之间来回确认，绝不直接瞬间抓取。

人物缓慢伸手，手从画框[上方/侧面]靠近镜头。由于真实的超近距离广角透视，[拇指与食指/手掌/工具前端]在前景显得巨大，皮肤纹理、指甲边缘、细小绒毛或工具磨损清晰可见；手靠得过近时局部自然虚化。摄影机像操作者本能避让般轻微后仰，构图短促偏移后立刻稳住，不得切镜。

把接触完整拆开：手指靠近 → 指尖对准 → 第一次轻触 → 调整夹持位置 → 施力 → 主物与承载面分离 → 接触阴影消失 → 微小颗粒或液体留下反馈 → 主物被举到人物视线高度。焦点先锁前景主物，手进入时短暂抓到指尖，再移到被夹持的材质表面，最后拉到人物眼睛与手中物之间；焦点接力必须清楚，不要持续抽动。

人物透过/贴近/转动[主物]仔细检查，以[语言、口音、音量、气息、情绪]逐字说：“[完整短台词]。”说话时写清嘴唇、眼神、手部和摄影机的反应；若无对白，明确写“本镜头无对白、无旁白”。

同期声只保留[衣料]、[呼吸]、[指尖接触材质]、[主物离开承载面的摩擦或轻响]以及远处模糊的[空间环境声]，近场与远场层次真实。

无 BGM，无配乐！

不要广告感，不要手指畸形，不要物体瞬移到手中，不要无接触阴影，不要夸张特效，不要慢动作，不要字幕、logo 或屏幕文字。
```

复刻结构：贴地首帧 → 前景材质 → 人物观察 → 手部极端透视 → 接触六中间态 → 三次以内焦点接力 → 完整短台词 → 触觉同期声。

## 群像对白模板

```markdown
极度真实可信的实拍质感！严格一镜到底！先以[全景/人群正面]建立共同空间。摄影机从人群侧面穿过并停在人群背后，确保共同观看物只从肩膀和头部间隙可见。每位人物说话时，镜头移动到其背后或侧后近景，保留前景遮挡，并在人物与共同观看物之间自然拉焦。对白必须逐句写全：[人物 A 以某语气说：“完整台词。”]；[人物 B 以某语气说：“完整台词。”]；[人物 C 以某语气说：“完整台词。”]。每句同时绑定说话者动作、摄影机位置和听者的非同步反应。最后一句中的[关键词]触发长焦推进到[关键视觉证据]，停留足够时间后缓慢 zoom out，让群体沉默收束。写清现场空气、衣料、脚步、呼吸和空间反射声。

无 BGM，无配乐！

不要镜头越过人群，不要全员同步转头或同步发笑，不要字幕、慢动作或人物看镜头。
```

## 遮挡转场模板

```markdown
极度真实可信的实拍质感！严格一镜到底！镜头保持连续拍摄。[移动主体]从画面[方向]进入，其身体或携带物形成真实前景遮挡。只有被遮挡扫过的区域从[空间 A]替换为[空间 B]；未扫过区域继续保持空间 A。转场中段必须同时看见：已替换区域、移动遮挡主体、尚未替换区域。移动主体出画后，空间 B 完整建立；新空间中的人物与设备继续进行各自独立的低强度活动。写清空间 A 与 B 的环境声如何随遮挡边界移动而自然交接。

无 BGM，无配乐！

不要数字溶解、淡入淡出、跳切、曝光闪断、空间方向翻转或遮挡边缘穿帮。
```

## 六模板调用纪律

1. 六个模板是镜头机制母版，不是六个固定题材；替换人物和故事时仍保留对应的空间、焦点、物理和声音逻辑。
2. 不得把六个模板全部拼进同一条 Prompt。先选择主要机制，最多叠加一个辅助模块。
3. 超低机位微观物理与超低机位前景拾取不同：前者核心是持续受力与材料运动，后者核心是人物手部进入、接触与认知变化。
4. 群像对白与制度空间群像不同：前者是一镜到底的说话者接力，后者允许有叙事理由的多机位，并以权力空间、命令链和突变为核心。
5. 发布会模板中的 zoom 必须是真实光学视野变化；遮挡模板中的空间替换必须由实体边界推进。
6. 所有正式交付都要经过 `review-rubric.md`；有对白必须逐句写全，所有模板都必须保留“无 BGM，无配乐！”。

## 精简版交付格式

用户只说“直接给 prompt”时：

1. 不写方法分析。
2. 不使用 YAML，除非用户指定。
3. 只保留一个标题和完整提示词。
4. 将必要的参数、声音和禁止项合并进 Prompt 正文。
5. Prompt 后只追加简短的“推荐时长”，不输出方法分析。
6. 有对白时逐句写出完整台词并绑定说话者、语气、动作、镜头与听者反应；无对白时明确写“本镜头无对白、无旁白”。绝不使用“自然交谈”“继续争论”等占位概述。

## 模型适配

- Seedance 2.5 默认使用 `@Image N`、`@Video N`、`@Audio N` 或 `@Clay Render N` 标记参考素材，并紧跟每份素材的职责，例如“参考 @Video 1 的运镜与节奏，参考 @Image 2 的人物外观与光线”。
- 30 秒复杂叙事优先用明确时间段组织多镜头；一镜到底则保持一条连续空间路径，不因时长增加而塞入隐形切镜。
- 延长已有视频时，先声明继续自 `@Video 1`，并锁定人物、场景、视觉风格、声音和叙事节奏。
- 编辑已有视频时，明确“只改什么、保持什么不变”，需要时用时间戳限定修改区间。
- 用户指定其他模型时，保留同一镜头逻辑，调整表达密度与参考图标记方式。
- 平台不支持原生声音时，仍可把声音作为剪辑/声音设计说明单列，不要假装模型会生成。
- 平台时长较短时，拆成多个连续 Prompt，并为相邻段重复最少量的角色与场景锚点。
- 平台支持首尾帧时，明确首帧不变量与尾帧目标；不要写无法同时满足的镜位。
