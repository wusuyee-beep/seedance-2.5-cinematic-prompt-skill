# 输出模板

## 默认长提示词模板

```markdown
[视觉合同：画幅、媒介感、写实程度、色彩、镜头形式；仅在用户已指定时写时长]

[首帧与空间：机位、前中后景、主体、光线、材质、连续性锚点]

[时间链：摄影机如何移动；人物与物体依次做什么；动作之间的因果和物理反馈]

[关键表演或对白：潜台词、微动作、焦点变化、其他人物的反应时差]

[收束画面：最终构图、视觉揭示或情绪落点]

[声音：同期声、对白]

[BGM：必须单独写明“无 BGM，无配乐！”]

[必要禁止项]
```

Prompt 代码块结束后另列：

```text
【推荐时长】
首选：[X 秒]
依据：[决定容量的核心动作、对白、运镜、反应或尾帧停留]
```

只有存在明确节奏取舍时才增加一个备选。不要把推荐时长复制进 Prompt 正文。

## 图生视频模板

```markdown
首帧严格延续参考图中的[人物身份/服装/道具/构图/光线/空间关系]，不改变[关键不变量]。

镜头从[首帧景别与机位]开始。[主体]先[微动作]，随后[触发动作]；摄影机因[叙事动机]沿[路线]移动，并在[对象 A]与[对象 B]之间[对焦行为]。[关键物体]受到[力]后，以[符合尺度与材质的运动]产生[结果]。[人物或群体]按[先后顺序]反应。

尾帧停在[明确构图]。保留[同期声]；避免[最可能的三到六种故障]。
```

## 用户指定时长后的单镜头模板

```markdown
[起始段：建立画面和动作起点]
[发展段：摄影机跟随核心动作，出现第一次信息变化]
[关键段：关键动作或视觉揭示，写清物理与焦点]
[收束段：人物反应和尾帧收束]
```

只有用户明确要求时间轴时，才把这些动作段换算为具体时间码；否则把节奏融入自然语言。绝不主动在 Prompt 正文添加秒数；正文之后仍需给出独立的推荐时长。

## 群像对白模板

```markdown
先以[全景/人群正面]建立共同空间。摄影机从人群侧面穿过并停在人群背后，确保共同观看物只从肩膀和头部间隙可见。每位人物说话时，镜头移动到其背后或侧后近景，保留前景遮挡，并在人物与共同观看物之间自然拉焦。对白依次为：[人物 A：语气与台词]；[人物 B：语气与台词]；[人物 C：语气与台词]。最后一句中的[关键词]触发长焦推进到[关键视觉证据]，停留足够时间后缓慢后拉，让群体沉默收束。
```

## 遮挡转场模板

```markdown
镜头保持连续拍摄。[移动主体]从画面[方向]进入，其身体或携带物形成真实前景遮挡。只有被遮挡扫过的区域从[空间 A]替换为[空间 B]；未扫过区域继续保持空间 A。转场中段必须同时看见：已替换区域、移动遮挡主体、尚未替换区域。移动主体出画后，空间 B 完整建立。不要数字溶解、淡入淡出、跳切或边缘穿帮。
```

## 精简版交付格式

用户只说“直接给 prompt”时：

1. 不写方法分析。
2. 不使用 YAML，除非用户指定。
3. 只保留一个标题和完整提示词。
4. 将必要的参数、声音和禁止项合并进 Prompt 正文。
5. Prompt 后只追加简短的“推荐时长”，不输出方法分析。

## 模型适配

- Seedance 2.5 默认使用 `@Image N`、`@Video N`、`@Audio N` 或 `@Clay Render N` 标记参考素材，并紧跟每份素材的职责，例如“参考 @Video 1 的运镜与节奏，参考 @Image 2 的人物外观与光线”。
- 30 秒复杂叙事优先用明确时间段组织多镜头；一镜到底则保持一条连续空间路径，不因时长增加而塞入隐形切镜。
- 延长已有视频时，先声明继续自 `@Video 1`，并锁定人物、场景、视觉风格、声音和叙事节奏。
- 编辑已有视频时，明确“只改什么、保持什么不变”，需要时用时间戳限定修改区间。
- 用户指定其他模型时，保留同一镜头逻辑，调整表达密度与参考图标记方式。
- 平台不支持原生声音时，仍可把声音作为剪辑/声音设计说明单列，不要假装模型会生成。
- 平台时长较短时，拆成多个连续 Prompt，并为相邻段重复最少量的角色与场景锚点。
- 平台支持首尾帧时，明确首帧不变量与尾帧目标；不要写无法同时满足的镜位。
