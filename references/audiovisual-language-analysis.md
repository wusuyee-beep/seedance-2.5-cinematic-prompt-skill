# DiDi_OK 六案的视听语言结构与复刻语法

## 分析方法

本文件把六案拆成五层：**词句功能 → 视听语言作用 → 模型执行证据 → 可替换变量 → 失败防护**。分析单位不是华丽形容词，而是每一段是否完成了明确任务。教材框架与书目见 `audiovisual-language-sources.md`。

六案可统一理解为：

> 视觉合同 → 视点与空间 → 主体/材质锚点 → 摄影机路径 → 事件因果链 → 焦点与遮挡 → 表演/物理中间态 → 声音空间 → 禁止项。

“严格、必须、始终、全程、绝不”只用于锁定最容易崩坏的环节；不能把每句话都变成口号。每条 Prompt 必须独立写明“无 BGM，无配乐！”。

## 先把四个常混淆的镜头词拆开

| 词 | 真正控制的变量 | DiDi_OK 式写法 | 不能这样写 |
| --- | --- | --- | --- |
| 手持 | 操作者身体造成的低频漂移、步伐起伏与构图修正 | 写清“呼吸式上下浮动、脚步带来的轻微侧向摆动、突发声后晚半拍回摇” | “疯狂抖动、越真实越抖” |
| 变焦 | 焦距连续变化，机位不变，画面范围被压缩或展开 | 写清起止景别、变焦速度、触发词或视觉目标 | 把 zoom out 写成摄影机后退却又要求透视不变 |
| 移动摄影 | 摄影机位置变化，产生视差、遮挡变化和空间揭示 | 写清从哪里到哪里、经过谁、被什么挡住、停在哪里 | 只写“镜头推进，很有电影感” |
| 拉焦 | 清晰平面变化，重新分配注意力 | 写清从谁/何物拉到谁/何物，以及为什么此刻改变 | 随机失焦、整段呼吸式抽焦 |

## 纪录片手持的五种可控抖动

1. **呼吸漂移**：静止观察时极轻微上下浮动，幅度小，不能让主体离开构图。
2. **步伐起伏**：跟拍时每一步带来低频垂直位移和轻微左右摆动；停步后逐渐减弱。
3. **突发后仰**：突然高声、冲击或物体靠近时，摄影机像操作者受惊般短促后撤或构图偏离，再修正。
4. **抢拍过冲**：被画外声吸引后快速回摇，略微超过目标，再小幅回摆锁定；只出现一次或少数几次。
5. **微距放大抖动**：超低机位时细小呼吸也会放大，应用短促、克制的位移，并让焦点回到接触面。

这些抖动都必须有身体或事件来源。无来源的高频振动会变成故障感，不是纪录片感。

## Case 1：超低机位微观物理过程

### 原文结构逐段功能

| 原文写了什么 | 结构功能 | 如何复刻 |
| --- | --- | --- |
| 画幅、超低机位、微观纪录片视角、贴近潮湿带灰尘的地面 | 第一段先锁视觉合同、观察尺度与表面坐标系 | 用“镜头中心离承载面约一个主体高度”或“镜头几乎擦地”明确高度；承载面的湿度、颗粒、裂缝成为尺度参照 |
| 多支小队与多色硬糖 | 建立多主体分区与运动方向，防止群体融成一团 | 给前景主队、左右副队和背景流量分别指定方向、速度与优先级 |
| 糖果尺寸、透明度、切面、气泡、糖霜；否定糖屑和塑料 | 材质身份与失败防护合写 | 每种关键材质都写“尺度＋表面＋内部＋边缘＋禁止误读” |
| 托举、推动、牵引、腿部抓地、触角摆动 | 将“搬运”拆成可见受力链 | 明确施力点、支点、发力姿态和负载反馈，动作与物体重量必须对应 |
| 翻滚、偏移、卡顿、再滚动、接触面交替、重心变化 | 为物理过程补中间态 | 事件链至少包含启动阻力、运动、受阻、重新施力、结果五段 |
| 前景主糖、左右副糖、背景经过 | 建立前中后景与注意层级 | 主体占据清晰焦平面；副事件可见但不争夺主叙事；背景只提供世界连续性 |
| 呼吸感手持、浅景深、边缘经过时虚化、再拉回足部 | 把摄影机写成贴近现场的观察者 | 微距抖动必须克制；焦点只因遮挡或主体位移短暂丢失，并明确恢复目标 |
| 白大褂人影完全模糊 | 背景提供尺度反差和世界观，不抢注意 | 背景人形只保留轮廓、移动和色块，绝不突然清晰 |
| 摩擦、磕碰、“咔哒”、底噪 | 用材质声音证明重量和表面 | 声音逐一绑定接触事件，并说明近距离被放大的听感 |

### 复刻公式

**微观视点合同 → 承载面尺度锚点 → 主体材质身份证 → 多组运动分区 → 施力链 → 接触面/阻力/重心的中间态 → 微距手持与焦点恢复 → 背景世界线索 → 材质同期声 → 误读禁区。**

### 必须新增的超低机位语法

- 说明镜头相对地面/桌面/液面的高度，而不是只写“低机位”。
- 指定前景物体离镜头极近时的局部遮挡和浅景深虚化。
- 指定镜头是否随主体贴地平移、原地观察或被主体逼近；三者不能同时含混出现。
- 抖动写成微距放大后的呼吸漂移，焦点必须回到“接触点、足部、边缘或表面纹理”之一。
- 让大尺度背景只作为模糊参照，形成“微观主体巨大化”的知觉效果。

## Case 2：制度空间群像、跟拍与物理突变

### 原文结构逐段功能

| 原文写了什么 | 结构功能 | 如何复刻 |
| --- | --- | --- |
| 写实、实拍、冷峻荒诞、黑色幽默、世界观连续 | 先定类型、调性与连续性 | 分开写“影像事实”和“情绪效果”；黑色幽默由表演反差与结尾产生，不靠夸张滤镜 |
| 摄影机贴着政客和跟班，从侧后绕到背后 | 选择跟随对象与限制视点 | 先指定摄影机跟谁，再规定可见范围；不要让镜头提前知道实验结果 |
| 晃动、漂移、偶尔失焦后重新对焦 | 形成记者在场感 | 每种不稳定都绑定跟拍、避让或紧张呼吸；主体丢失后必须迅速恢复 |
| 政客冷漠；跟班小步紧跟、偷看、搓手、勉强笑 | 以动作呈现身份关系和潜台词 | 抽象词“谄媚”必须被三种以上微行为证明 |
| 观察室、玻璃、试验场逐层揭示 | 建立空间嵌套和观看权力 | 写清外层人群—玻璃界面—内层被观察者；视线、声音和焦点怎样穿过界面 |
| 中近景、特写、远机位展示囚犯与空场 | 用景别变化调节心理距离 | 每个景别承担一项任务：表情、身体状态或空间压迫，不为炫技切换 |
| “Hit him.”等逐句对白与犹豫、祈求、道歉 | 对白驱动行动并建立伦理压力 | 每句绑定说话者、语气、动作、镜头位置、听者反应和下一步因果 |
| 从近处科研人员拉焦到远处囚犯 | 把控制者与执行者放在同一权力画面 | 拉焦两端必须都在既定构图中，焦点变化即权力注意转移 |
| 拳击后什么也没发生；准备回头时突然爆裂 | 先制造空拍延迟，再在中间态打断预期 | 关键突变最好发生在“动作刚开始但未完成”的瞬间，避免仪式化倒计时 |
| 糖果散射、碰撞、滚动，衣服塌落 | 用支撑消失和二次运动证明物理 | 突变不是一帧替换；写清原身体消失、服装失去支撑、物体初速度、落点和二次弹跳 |
| 有人退、有人僵、有人瞪眼 | 群体反应错峰 | 至少分三类反应，并给出先后，不允许全员同步转头或尖叫 |
| 跟班解释与政客回应 | 用结尾对白重新解释事件 | 收束句必须改变观众对制度、人物或结果的理解，不只是总结剧情 |

### 复刻公式

**世界合同 → 跟随对象与受限视点 → 权力关系微表演 → 外层观察者/界面/内层对象 → 命令对白链 → 焦点跨层移动 → 行动与短暂停顿 → 中间态突变 → 真实物理余波 → 错峰反应 → 反讽对白收束 → 分层同期声。**

### 多机位使用纪律

- 这是六案中允许明确切镜的母版。每次切换必须回答“新机位补充了上一机位看不到的什么”。
- 切镜前后保持人物方向、玻璃内外关系与视线轴线稳定。
- 远景负责空间权力；中近景负责行动；特写负责伦理压力和微表演；不要随机轮换。
- 突发事件后的镜头可以抢拍式回摇或快速切回权力人物，但摄影机应晚半拍，不得提前构图等待爆裂。

## Case 3：发布会/公共发言纪录片长镜头

### 原文结构逐段功能

| 原文写了什么 | 结构功能 | 如何复刻 |
| --- | --- | --- |
| 严格一镜到底、记者手持、重大信息将公布 | 视觉合同与摄影机身份 | 明确摄影机是人群中的记者、距离受限、会被身体遮挡和声音吸引 |
| 从 LED 标识极近特写开始 | 先给公共机构/事件证据 | 标识必须清晰、完整、无乱码；如无必要品牌，可换成建筑细节、徽记或信息板 |
| 缓慢 zoom out，机位仍在人群中 | 通过变焦扩大信息而非改变透视 | 写明从局部特写到人物与环境同框；若摄影机同时移动，要分别描述移动和变焦 |
| 踮脚、呼吸浮动、横向偏移、短暂失焦再恢复 | 建立身体在场 | 抖动来源是拥挤人群中的站姿和观察，不是持续乱晃 |
| 从发言人耳侧擦过，再到侧前方 | 用近距离遮挡自然揭示人物 | 摄影机路径必须可绕行，不能穿过身体；耳侧只作为短暂前景，不长期遮脸 |
| 人物身份、外貌、克制表演、不看镜头 | 建立公众形象与现场行为 | “可信”用眼神落点、语速、呼吸、手势幅度证明 |
| 一整段逐字发言 | 让台词承担信息与叙事转折 | 不得摘要；按句写清停顿、重音、语气与现场反应，但避免人人同步反应 |
| 关键词时焦点从眼睛游到背景标识再拉回 | 把语言关键词变成视觉关联 | 焦点偏移必须由关键词触发，并建立“人说的话—机构符号”的关系 |
| 快门、记者移动、衣料、低语、空调 | 构成公共空间声场 | 近场声清楚、远场声弱；对白始终优先可懂 |

### 复刻公式

**公共事件压力 → 机构/场所证据特写 → 有动机的缓慢变焦 → 前景人体擦过 → 发言者侧前方稳定构图 → 完整逐句发言 → 关键词触发拉焦 → 克制反应 → 现场声收束。**

### 变焦与手持的组合规则

- 变焦必须写“从何景别到何景别”，并说明为什么此刻扩展或收窄信息。
- 变焦期间手持起伏保持低频，不增加高频震颤；否则主体边缘会产生不必要的数码故障感。
- 长对白中只安排少量、可解释的摄影事件：一次构图微调、一次短暂遮挡、一次关键词拉焦即可。
- 发言者始终面向现场对象而不是镜头；摄影机是观察者，不是广告机位。

## Case 4：移动遮挡空间替换（已有模板）

### 结构提炼

**旧空间证据特写 → 变焦建立完整旧空间 → 实体移动主体入画 → 遮挡扫过区域逐步替换 → 旧空间/遮挡边界/新空间三者同框 → 新空间完成 → 尾帧持续生活。**

复刻关键不在“遮满屏后切换”，而在中段必须看见转换边界。遮挡物的位置就是空间替换的进度条；摄影机方向、运动速度、曝光与人物行为都要连续。

## Case 5：超低机位前景拾取与极端近大远小

### 原文结构逐段功能

| 原文写了什么 | 结构功能 | 如何复刻 |
| --- | --- | --- |
| 贴地、散落物之间仰拍、前景某物最清晰 | 首帧同时建立尺度、机位和焦点优先级 | 指定镜头几乎贴地，前景主物距镜头最近；其余物体形成可辨识但不抢焦的层次 |
| 材质、磨损、高光、灰尘 | 防止前景道具塑料化或漂浮 | 写尺度、重量、表面瑕疵、与地面接触阴影 |
| 人物从镜头上方出现并观察 | 让远处人物进入微观世界 | 先让眼神搜寻和呼吸建立意图，再让手进入，不可直接瞬间抓取 |
| 手指靠近镜头时巨大，皮肤纹理可见 | 利用广角近距离透视制造触觉临场感 | 指定手从画框何处进入、离镜头极近、哪部分暂时失焦，避免手掌无边膨胀 |
| 靠近、夹住、施力、离地、举起、端详 | 完整接触因果链 | 拾取至少写六个中间态；道具离地时必须有接触声、阴影变化和焦点重新分配 |
| “Candy?”短对白 | 认知变化的声音落点 | 台词短但仍需逐字、音量、气息、口音/情绪和说话时动作 |
| 衣料、呼吸、摩擦、远处环境声 | 从近到远建立空间 | 超近声细致但不能失真；远处声保持低强度，避免抢对白 |

### 复刻公式

**贴地首帧 → 前景主物材质与接触阴影 → 人物从高处进入并观察 → 手指以极端透视逼近 → 对焦迟疑 → 接触/夹持/施力/离地 → 焦点由地面物转向手中物与眼睛 → 完整短台词 → 触觉同期声。**

### 超低机位与抖动规则

- 镜头高度、前景物距镜头的相对距离、人物所在方位必须同时写清。
- 手接近镜头时可引发轻微本能后仰或构图偏移，但不能真的切镜。
- 自动对焦可先抓到指尖，再短暂游移到道具表面，最后回到人物眼睛；最多三次明确焦点接力。
- 广角近大远小来自距离关系，不要只靠“巨大手指”形容。

## Case 6：共同观看物驱动的群像对白（已有模板）

### 结构提炼

**共同空间全景 → 摄影机穿到人群背后 → 短暂完整揭示共同观看物 → 人群重新形成遮挡 → 说话者接力与焦点接力 → 最后一句触发长焦视觉证据 → 缓慢后拉 → 群体沉默。**

复刻重点是保持摄影机的观察位置纪律：谁说话就移动到谁背后或侧后，但镜头始终不越过群体。共同观看物既是空间锚点，也是对话的视觉证据。

## 复刻前的逐字审查

生成后逐句标注其功能。任何一句如果既不控制视觉合同、空间、动作、表演、物理、焦点、声音，也不防止明确故障，就应删除或改写。

1. 开头是否一口气锁定写实性、镜头形式、摄影机身份和最重要的空间纪律？
2. 每次移动、变焦、拉焦、抖动是否有事件或人物动机？
3. “低机位”是否写到相对高度、前景遮挡与主体尺度？
4. “真实”是否被材质、受力、反应时差、操作失误与同期声证明？
5. 对白是否逐句完整，并绑定说话状态、镜头和听者反应？
6. 群像是否各自反应，避免同步转头、同步笑、同步惊叫？
7. 是否明确“无 BGM，无配乐！”，并把画内有源音乐与后期配乐区分？
8. 禁止项是否只针对本镜头高概率失败，而不是复制通用负面词表？
